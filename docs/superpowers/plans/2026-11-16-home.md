# תוכנית: מסך הבית (16.11.26)

## מה הבית צריך לתת

פתיחה בבוקר, ובמבט אחד: ברכה, מה קורה עכשיו, מה הבא, ומה פתוח (מטלות, משימות, מבחנים). הכול ברשימה אחת שגוללים, בלי לשוניות.

```
┌───────────────────────────────┐
│ בוקר טוב פבל                  │  ברכה לפי השעה
├───────────────────────────────┤
│ עכשיו · מבוא למיקרו · 107      │  רק אם יש שיעור עכשיו
│ עד 12:00 · עוד 25 דק'          │
├───────────────────────────────┤
│ הבא · מתמטיקה א' · 101         │
│ היום 14:00 · בעוד שעתיים        │  או "מחר 08:30", "ביום ג' 10:15"
├───────────────────────────────┤
│ מטלות (3)                      │  באיחור קודם, ואז לפי תאריך
│  ...                           │  הוגשו (N) מקופל
├───────────────────────────────┤
│ משימות (1)                     │  הושלמו (N) מקופל
├───────────────────────────────┤
│ מבחנים · הבאים                 │  3 הקרובים + "כל המבחנים (12)"
└───────────────────────────────┘
```

## ברכה

| שעות | ברכה |
|---|---|
| 05:00–12:00 | בוקר טוב |
| 12:00–15:00 | צהריים טובים |
| 15:00–18:00 | אחר צהריים טובים |
| 18:00–22:00 | ערב טוב |
| 22:00–05:00 | לילה טוב |

שינויים מההצעה שלך: ערב עד 22 ולא עד 21 (משמרת סגירה נגמרת ב-22, ובשעה כזו "לילה טוב" נשמע כמו פרידה); בוקר מ-05 כדי שלא יהיה "לילה טוב" בחמש וחצי. "אחר צהריים" בלי ה' (הנוסח הנפוץ). השם מהפרופיל (`profileOf(items).name`); בלי שם: רק הברכה. השעה לפי `nowMin()` (שעון ישראל). מתעדכן ב-`nowTick` (כל דקה).

## עכשיו והבא

- **מקור:** `evsForWeek` של השבוע הזה והבא, רק שיעורים (`src:'base'`) ומבחנים, בלי שיעורים מבוטלים. משמרות ופריטים שלי לא נכנסים (בקשה: "שיעור").
- **עכשיו:** אירוע של היום שההתחלה ≤ עכשיו < הסוף. שורה: שם, חדר, "עד HH:MM · עוד N דק'". אין: השורה לא מוצגת.
- **הבא:** האירוע הבא שמתחיל אחרי עכשיו (גם מחר או אחרי סוף שבוע/חופש, עד סוף הסמסטר). "היום 14:00 · בעוד שעתיים", "מחר 08:30", "ביום ג' 10:15", "ב-22.01" (רחוק). אין בכלל (אחרי הסמסטר): לא מוצג.
- **לחיצה:** פותחת את חלון השיעור (`openCancel`), שכבר מראה את המטלות הפתוחות של הקורס.
- **core (טהור, עם בדיקות):** `nowNext(today, min, items)` → `{now, next}` עם `daysAhead`, `minsLeft`, `minsTo`.

## הרשימות

- הלשוניות (`#upSeg`) יוצאות. שלושה חלקים זה מתחת לזה, כל אחד עם כותרת ומספר. סדר: מטלות, משימות, מבחנים.
- **מטלות:** כמו היום (קבוצות באיחור / השבוע / החודש / אחר כך), כל הפתוחות; "הוגשו (N)" מקופל בסוף החלק; "הדבקה מהמודל" בסוף החלק.
- **משימות:** הפתוחות; "הושלמו (N)" מקופל. אין משימות: שורה שקטה "אין משימות".
- **מבחנים:** 3 הקרובים, ואז "כל המבחנים (12)" שפותח את כולם (כולל מה שעבר, מעומעם).
- **ה-+ בבית:** תפריט קטן? לא. ברירת מחדל: משימה. (מטלה דרך הסוג "הגשה" בחלון.)
